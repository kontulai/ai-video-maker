# Web App Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A local web app that walks a video project through six editable phases (setting, talk track, scene plan, video, overlays, final) on top of the existing pipeline.

**Architecture:** FastAPI in `server/` imports `make_video`, `callouts` and `segmentation` and runs long jobs in one background thread per project, persisting `project.json` and `job.json` in `projects/<id>/` (the project folder is the pipeline's run folder). A React + TypeScript + Vite app in `web/` talks to `/api`, follows job logs over server-sent events, and holds the overlay editor. The pipeline gains only a log hook, an optional planner image, a preview-image generator and output-name parameters.

**Tech Stack:** Python 3.14, FastAPI, uvicorn, pydantic 2, google-genai, requests, ffmpeg via imageio-ffmpeg; React 18, TypeScript 5, Vite 5, react-router-dom 6.

**Spec:** `docs/superpowers/specs/2026-10-23-web-app-design.md`

## Global Constraints

- The CLI (`make_video.py`) keeps its behaviour; `.venv/bin/python -m pytest -q tests` stays green (53 tests before this plan).
- No model call or video generation ever happens without an explicit button: the server runs generation only from the `POST .../run/...` routes.
- Only one job runs per project at a time; a second start answers HTTP 409.
- API keys stay in `.env`; nothing under `/api` returns them. `.env` is never committed.
- Project files keep the CLI names: `scene.txt`, `talk_track.txt`, `voice.mp3`, `alignment.json`, `segments.json`, `plan.json`, `prompts.json`, `callouts.json`, `clips/`, `preview_N.png`, `rough_cut.mp4`, `callouts.ass`, `final.mp4`.
- Overlay times in `callouts.json` are drawn exactly; overlaps are neither trimmed nor warned about. Video prompts carry no layout hints.
- Aspect ratio `16:9` or `9:16`; resolution `360p|720p|1080p|4k`; longest scene 10 to 30 s; density `off|low|medium|high`; text retries 0 or more. Defaults: `16:9`, `720p`, `30`, `medium`, `2`.
- Tests need no API keys: Gemini, Omni and ElevenLabs are faked as in `tests/test_end_to_end.py`.

## Review Focus

1. A job that dies with `sys.exit` inside the pipeline (ElevenLabs error, clip failing three times): the job record must say `failed` with the message and the phase must stay editable. Test in Task 3.
2. Regenerating scene 2 after scene 1 was regenerated: scene 2's prompt must be re-fitted to the new footage, not keep the `IN FRAME NOW` line of the old. Test in Task 6.
3. Editing the production bible marks every scene stale; editing one shot marks only its scene. Test in Task 5.
4. A hand-edited overlay survives "Regenerate suggestions" unless the user says to replace it. Test in Task 7.
5. A project id or file name in a URL must never escape `projects/` (`..`, absolute paths). Test in Task 2.

**Interfaces:**
